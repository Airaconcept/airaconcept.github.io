GitHub 好项目 2026-10-09

alibaba/open-code-review

阿里把内部用了两年的 AI 代码审查工具开源了，命令行叫 ocr。

  • 文件筛选、分组、规则匹配用确定性代码兜底，只把动态判断交给大模型
  • 官方称同模型下精确率和 F1 高于 Claude Code，token 约 1/9；代价是召回率更低
  • Apache-2.0，约 4.5 万 Star（2026-10-09）
  • 安装：npm install -g @alibaba-group/open-code-review
